# Обновление офлайн-карты Украины между версиями приложения

Сборка: 0.10.6-alpha.

## Использование уже скачанных файлов

В предыдущих версиях приложение `ua.obdgps.nav` сохраняло скачанные
векторные файлы во внутренней памяти **этого же приложения**:

- `files/offline-vectors/selected.map` — Mapsforge карта Украины;
- `files/offline-vectors/selected.poi` — база мест/адресов Mapsforge POI;
- `files/offline-vectors/download-ukraine.map.part` и
  `download-ukraine.poi.part` — незавершённая загрузка, которую можно
  продолжить.

Эти же пути использует новая версия. Никакой миграции/копирования
гигабайтного файла не требуется: проверяем данные *на месте*.
При обычном обновлении APK с **совместимой цифровой подписью**, без удаления
приложения и его данных, Android оставляет эти файлы в целости.

Экран «Офлайн-карты» теперь проверяет ранее сохранённые данные:
- карта: заголовок Mapsforge и размер не меньше 40 МБ;
- база POI: заголовок SQLite, наличие таблиц `poi_data` и
  `poi_index`, доступность хотя бы одной записи в каждой таблице, размер
  не менее 8 МБ;
- проверка POI выполняется в рабочем потоке, не блокируя UI;
- маленькие ранее импортированные областные файлы не называются полной
  картой Украины, но не удаляются и могут использоваться как резервные.

При запуске скачивания файлов всей Украины уже проверенные файлы
пропускаются, а недостающие/повреждённые загружаются из публичного
каталога `download.mapsforge.org` по HTTPS, без собственного сервера.
Прерванные загрузки сохраняют файл `.part` и поддерживают продолжение.

## Что удалено из интерфейса

- Импорт MBTiles/подробных карт областей и переключатель регионов.
- Кнопки загрузки областей и обзорной карты с пользовательского сервера.
- Настройки собственного HTTPS-каталога, Wi-Fi ограничения и
  автоматического скачивания областей при запуске.

При этом ранее сохранённые файлы `files/offline-region-packs/*.map/.poi`
не удаляются и продолжают служить резервным источником при отсутствии
общенациональных файлов. Уже сохранённые растровые MBTiles-файлы и
просмотренные тайлы также не стираются.

В разделе «Офлайн-карты» есть необязательное восстановление готовых
национальных `.map` и `.poi` через системный выбор файлов, если данные
были сохранены пользователем отдельно (например, в Downloads).

## Важная оговорка о подписи Android

Android **не даёт** устанавливать обновление поверх приложения с другой
подписью. При несовпадении подписи необходимо сначала отдельно
скопировать скачанные файлы/сделать резервную копию. **Не удалять старый
APK до сохранения данных:** при удалении приложения Android удаляет
файлы во внутренней памяти приложения, и новая версия не сможет их найти.
Особенно важно для debug APK из отдельных CI сборок: Android debug keys
могут различаться между сборками. Успешная компиляция новой версии не
гарантирует совместимость подписи с предыдущей установкой.


### Проверенная несовместимость прежних тестовых APK

Проверка APK Signature Scheme v2 показала, что опубликованные тестовые
сборки 0.10.4-alpha и 0.10.5-alpha имеют **разные сертификаты подписи**.
Поэтому рассчитывать на обновление поверх другой GitHub Actions debug
сборки без потери данных нельзя. Не пытаться решить эту ошибку удалением
приложения, пока не экспортированы `.map` и `.poi`.

В репозитории добавлен безопасный скрипт для Windows:
`tools/backup-offline-ukraine.cmd`. Он требует установленного ADB
(Android platform-tools), включённой USB-отладки и установленного старого
debug APK; через `adb exec-out run-as ua.obdgps.nav cat` экспортирует
`selected.map` и `selected.poi` на компьютер без изменений в телефоне.
Перед удалением старого приложения нужно убедиться, что оба файла имеют
ожидаемые размеры и надёжно сохранены. Если `run-as` недоступен,
не удаляйте приложение и используйте другой согласованный способ резервной
копии.

После установки новой APK пользователь копирует `ukraine.map` и
`ukraine.poi` обратно на телефон (например, в Downloads) и выбирает
в «Офлайн-карты» пункты «Выбрать готовую карту Украины (.map)» и
«Выбрать готовую базу адресов Украины (.poi)». Приложение проверяет
формат и сохраняет файлы как `selected.map` и `selected.poi`.

## Ручные проверки

1. Установка поверх версии с сохранёнными файлами: карта и POI найдены,
   повторное скачивание не предлагается, поиск адресов работает без сети.
2. Только `selected.map`: показать отсутствие базы адресов, кнопка
   «скачать адреса» получает только POI, карта остаётся нетронутой.
3. Только `selected.poi`: скачать только карту, POI остаётся нетронутой.
4. Отсутствуют оба файла: можно скачать общий комплект через Mapsforge.
5. Есть старые `offline-region-packs/*.map/.poi`: они не исчезают, но
   не требуют HTTPS-сервера и доступны как резерв.
6. Есть неполный `download-ukraine.map.part`: продолжение загрузки.
7. Проверка ошибочного формата `.map` или SQLite POI показывает сообщение,
   не говорит, будто файлы готовы.
8. Без интернета открыть ранее проверенные векторную карту и адресную базу.
